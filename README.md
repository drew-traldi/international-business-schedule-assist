# 🌍 Meridian

World clock and meeting planner. See every team's local time and slide through the day to find a slot that works for everyone.

**▶ Use it here: [https://drew-traldi.github.io/international-business-schedule-assist/](https://drew-traldi.github.io/international-business-schedule-assist/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
